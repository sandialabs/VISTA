# Image Generation Script

Generate images using text-to-image models via Replicate's API.

## Setup

1. Install the Replicate Python package:

   ```bash
   pip install replicate
   ```

2. Add your Replicate API token to the project `.env` file:

   ```
   REPLICATE_API_TOKEN=r8_yourTokenHere
   ```

   You can get a token at https://replicate.com/account/api-tokens

## Supported Models

| Model | ID | Notes |
|---|---|---|
| Stable Diffusion | `stability-ai/stable-diffusion` | Default. Multiple outputs, configurable steps/guidance. |
| P-Image | `prunaai/p-image` | Sub-1-second generation. Aspect ratio presets, LoRA support. |

## Basic Usage

```bash
# Use the default prompt file (scripts/image_prompt.md)
python scripts/generate_images.py

# Inline prompt
python scripts/generate_images.py "a cat wearing a top hat"

# Multiple images
python scripts/generate_images.py "sunset over mountains" --count 3

# Custom dimensions (Stable Diffusion, must be multiples of 64)
python scripts/generate_images.py "pixel art castle" --width 768 --height 768

# Read prompts from a file (one per line, # comments ignored)
python scripts/generate_images.py --prompts-file my_prompts.txt
```

## Using P-Image

```bash
# Basic
python scripts/generate_images.py --model p-image "flowers in a glass vase"

# With aspect ratio
python scripts/generate_images.py --model p-image "a whale underwater" --aspect-ratio 16:9

# Custom dimensions (must be multiples of 16)
python scripts/generate_images.py --model p-image "street musician" --aspect-ratio custom --width 1024 --height 576

# Prompt upsampling (let an LLM enhance your prompt)
python scripts/generate_images.py --model p-image "simple flower" --prompt-upsampling

# With LoRA weights
python scripts/generate_images.py --model p-image "portrait" \
  --lora-weights "huggingface.co/owner/model-name" \
  --lora-scale 0.5
```

## Default Prompt File

When run without a prompt or `--prompts-file`, the script reads from
`scripts/image_prompt.md`. Edit that file to change what gets generated by
default. Lines starting with `#` are treated as comments and ignored.

## Output

All generated images are saved to `tmp/generated_images/` in the project root.
This directory is git-ignored. Filenames include a timestamp, the model name,
and a sanitized version of the prompt.

## Full Options Reference

Run `python scripts/generate_images.py --help` for all available flags.

### Stable Diffusion Options

| Flag | Default | Description |
|---|---|---|
| `--count, -n` | 1 | Number of images per prompt |
| `--width, -W` | 512 | Image width (multiple of 64) |
| `--height, -H` | 512 | Image height (multiple of 64) |
| `--guidance-scale, -g` | 7.5 | Classifier-free guidance scale |
| `--steps, -s` | 50 | Number of inference steps |
| `--negative-prompt` | -- | Things to exclude from the image |
| `--scheduler` | -- | Diffusion scheduler (DDIM, K_EULER, etc.) |
| `--seed` | -- | Random seed for reproducibility |

### P-Image Options

| Flag | Default | Description |
|---|---|---|
| `--aspect-ratio` | -- | 1:1, 16:9, 9:16, 4:3, 3:4, 21:9, 9:21, or custom |
| `--width, -W` | -- | Width when aspect-ratio is custom (multiple of 16) |
| `--height, -H` | -- | Height when aspect-ratio is custom (multiple of 16) |
| `--prompt-upsampling` | off | Enhance prompt with an LLM before generation |
| `--disable-safety-checker` | off | Disable the safety filter |
| `--lora-weights` | -- | HuggingFace LoRA weights URL |
| `--lora-scale` | -- | LoRA strength (0.5 is typical) |
| `--hf-api-token` | -- | HuggingFace token for private LoRAs |
| `--seed` | -- | Random seed for reproducibility |
